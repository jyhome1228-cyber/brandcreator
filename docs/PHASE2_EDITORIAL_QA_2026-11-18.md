# BRAMER V2 · 2차 문서 가독성/응용 배치 검증 (2026-11-18)

## 목표
보태니컬·브론디 등 사용자가 공유한 실제 브랜드 가이드라인의 **로고 규칙, 컬러 체계, 서체 위계, 명함·서식 응용**을 참고해, BRAMER V2의 26페이지 결과물을 실제 브랜드별 입력 변화에 더 견고하게 대응시키는 것.

본 PR은 **시각 품질 관련 코드 개선과 자동 회귀검사** 단계다. 아직 승인된 건강미 SVG 원본과 브라우저 스크린샷 기반 시각 검수 자료가 없으므로 외형/인쇄 최종 승인으로 표현하지 않는다.

## 개선 항목

| 문제 | 작업 | 검증 |
|---|---|---|
| 밝은 메인컬러를 흰 문서 배경에서 사용하면 제목이 흐려짐 | 흰 바탕의 문서 제목에 대비 기반 다크 폴백 컬러 적용. 브랜드 컬러 자체는 보존 | 밝은 컬러 fixture 검사 |
| 긴 브랜드명·페이지 제목이 인접 요소나 우측 여백을 침범할 수 있음 | 헤더/하단 브랜드명에 글자 폭 추정 기반 폰트 축소 | 장문 fixture 검사 |
| 브랜드 소개·슬로건이 한 줄로 길게 넘어가는 문제 | 최대 3줄 슬로건, 최대 7줄 소개 문구, 폭에 따른 크기 보정 및 정보 위계 정돈 | 장문 fixture 검사 |
| 명함의 작은 글씨와 불안정한 연락처 행간 | 90×50mm 앞뒤면 SVG를 7mm 안전 여백, 분명한 이름/직책 위계, 정렬된 연락처로 개선 | 명함 규격·여백 검사 |
| 가이드라인 명함 예시가 입력값을 지나치게 길게 반복 | 앞면/뒷면 카드 중심으로 정리하고 실제 연락처를 일관된 정보 구조로 요약 | 26P/연락처 회귀검사 |
| Color Contrast에 적용 근거가 없이 '시각적 검토 필요' 문구만 존재 | 단색 로고/배경에 대해 RGB 상대명도 기반 명암 대비 비율(:1)을 명시 | 대비 문구·비율 검사 |

## 반영 기준 및 정확성 주의
- **문서 생성 페이지 26장과 17개 제작 항목 유지**.
- 대비 수치는 오직 **브라우저에서 선택한 흑백 단색 로고색과 배경색의 수치상 대비**를 나타낸다. 실제 다색 로고/세부 획/브랜드 공식 승인 규정의 적합성 판단값으로 사용하지 않는다.
- 명함 SVG는 편집용 원본이며 인쇄용 최종 승인을 받지 않았다. 도련·컬러 모드·서체 라이선스·실물 가독성 테스트 필요.
- 자동 글자 크기 조절은 추정 글자 폭을 사용하기 때문에 아주 긴 조합형 텍스트 및 사용자 지정 서체에 대해서는 브라우저 실측 검수가 필요.
- 보태니컬·브론디의 스타일은 비교 참고이며 기존 이미지/문서 내용을 복제하는 작업이 아니다.

## 재현 테스트
`npm run qa:guidelines`에서 6종 합성 로고, 26페이지 문서, 명함/스티커/레터헤드/봉투 SVG XML 구조 외에 **장문 브랜드명·슬로건·연락처, 밝은 브랜드 컬러 가독성, 수치 대비 표기 및 명함 안전 여백**까지 점검.

## 다음 단계: 실브랜드 브라우저 시각 검수
1. 승인된 건강미 SVG (또는 다른 실제 브랜드 마스터 파일)를 업로드.
2. 생성된 26페이지를 브라우저에서 100% 및 200% 스케일로 확인하고 페이지별 로고 크롭, 잔여 여백, 기준선, 텍스트 오버플로, 배경 대비, 서체 대체 등을 기록.
3. 명함 앞면/뒷면, 스티커, 레터헤드, 대소봉투를 PDF/SVG로 내보낸 뒤 인쇄소 제작 규격과 비교.
4. 실제 출력 결과와 보태니컬·브론디의 페이지 편집 밀도·위계를 비교해 레이아웃 템플릿 고도화.
5. 문제가 확인된 개별 SVG와 재현 방법을 회귀검사 fixture로 추가.

**현재 완료된 검증은 자동 코드 검사이지 화면 캡처나 실물 인쇄 검수가 아니다.**
