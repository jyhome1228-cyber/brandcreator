# BRAMER V2 · 페이지 내용 정합성 개선 기록

**적용 범위:** 17개 기본 항목, 26페이지 결과물. 기존 BRAMER 생성 엔진의 페이지 제목과 실제 SVG 시각 예시 불일치 수정.

## 발견된 핵심 문제
- 'Logo Grid Detail'의 실제 콘텐츠는 종전 엔진의 로고 컬러 버전 사례였다.
- 'Clear Space Detail'의 실제 콘텐츠는 종전 엔진의 Incorrect Usage 사례였다.
- 'Monochromatic'이라는 제목에 RGB/CMYK 브랜드 컬러 팔레트가 들어갔다.
- 'Brand Colors'라는 제목에 근거가 없는 60/30/10 색상 비율 제안이 들어갔다.
- Logo 챕터 목록에 현재 제공하지 않는 'Logo variations'가 등장했다.
- Incorrect Usage는 원본 로고에 X만 겹치는 수준이라 어떤 변형이 금지되는지 불명확했다.

## 변경
1. **Logo Grid Detail:** 실제 SVG 시각 경계의 가로세로 비율 및 기준 축을 도식화. 서체·획의 광학적 판단은 최종 검토로 명시.
2. **Clear Space Detail:** 같은 로고를 정상 보호 공간과 침범 예시로 구분. 프로젝트 사용자가 정한 X 값을 반영.
3. **Monochromatic:** 밝은 배경의 검정 단색과 어두운 배경의 흰색 단색 로고를 실제로 SVG 생성.
4. **Brand Colors:** 기존 엔진의 정확한 HEX·RGB·CMYK 컬러 정보를 연결. '60/30/10' 자동 고정 배분은 기본 결과물에서 제거.
5. **챕터 분리:** Logo/Color/Typography 세 챕터의 목록을 새 17개 항목에 맞춤.
6. **Incorrect Usage:** 회전, 비율 왜곡, 낮은 대비를 실제로 시연하는 4칸 예시.
7. **페이지 ID:** 모든 페이지 중복 제거. 기존 페이지 수 26 유지.
8. **회귀검사:** 실제 그림 종류와 목차의 일치, 색상 값, 금지 예시 및 XML 유효성 자동 검사.

## QA
GitHub Actions에서 `npm run qa:guidelines`와 `npm run build` 검사 통과를 병합 기준으로 사용.

## 남은 검증
- 실제 브랜드 공식 SVG로 26페이지를 인쇄·디지털 화면에서 육안 검토.
- 폰트 파일 의존성 및 윤곽선화 필요 여부.
- 최소 크기 및 Clear Space 제안의 승인 기준 비교.
- 명함, 스티커, 봉투의 실제 인쇄소 전개도·도련·컬러 모드 적합성.

**주의:** 자동 테스트 합격은 SVG 문법과 문서 구성의 정합성 확인일 뿐, 실제 상표 규정 승인이나 시각 디자인 품질을 인증하지 않음.
